# School board — Ship / Demo Friday pins

Copy one into a new school-board topic. Text only. No certificates, no gated tiers. Cadence idea: **scope midweek → tiny ship → Friday demo + friend review**.

1. **Demo Friday — Build proof** — Post two usernames that were online together and one sentence about the DM (or other friend-visible slice) that proved Path 01. Link optional.

2. **Finish Friday — one gap closed** — Name the Finish path you moved (02–06). What was broken before, what prove-it check passes now? No secret values.

3. **Ship Friday — health + rollback** — Redacted `/health` ok (or what failed), which host, and one rollback/next-step note if the demo goes sideways.

4. **Security drill swap** — Pick an optional Path 05 security packet (session regenerate, redirect allowlist, frame denial, session-store ACL). Post the title + whether you want a friend review. Accepting is voluntary; they use their own AI usage.

5. **Help packet handoff** — Drop a path help-packet title you’re stuck on. A friend who accepts sends a PR back — not a screenshot of your chat history.
