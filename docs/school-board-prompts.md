# School board — weekly starter prompts

Short pins for the CodeFriends school board. Copy one into a new topic when the cohort needs a weekly focus. Keep it text-only; no certificates, no gated tiers.

1. **Friend-visible Friday** — Who shipped Path 01 this week? Drop the two usernames that were online and one sentence about the DM that proved it.

2. **Auth honesty** — Name one provider that is live on your instance and one that is blocked (and why). No pretend buttons.

3. **Restart test** — What durable thing did you write, restart, and still see? Table or feature name only.

4. **Help packet swap** — Post a path help-packet title (not secrets) you need a friend on. Accepting is voluntary; they use their own AI usage.

5. **Health check** — Paste a redacted `/health` ok (or what failed) and which host you hit. Tunnel vs app — which one was wrong last time?
