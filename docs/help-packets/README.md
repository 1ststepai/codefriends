# Path help packets

Portable markdown briefs matched to [School Paths](../school-paths/README.md). Copy a template, fill the blanks, and hand it to a friend so they can finish a stuck step **on their own AI usage**, then send a PR back.

These are **templates** — not the Library “Help packet” creator drafts stored in `help_packets`. Use either:

- the in-app Help packet form on the Library tab (general template), or
- one of the path-specific files below when you are mid-path.
